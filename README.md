# Bus Reservation System
## CS206 — Computer Organization (Assembly Language / EMU8086)

**Overview:**
Built for a Computer Organization course, this project implements a Bus Reservation System in EMU8086, letting users browse available bus routes, reserve seats, calculate fares, and apply a student discount where applicable. A menu-driven interface walks the user through schedules, the reservation process, price calculation, and exit.

**Objectives:**
- Build a working reservation system using low-level Assembly programming.
- Present users with bus schedules and reservation choices.
- Calculate fares based on the selected reservation.
- Apply a student discount when eligible.
- Handle invalid menu and schedule inputs gracefully.
- Gain hands-on experience with low-level programming via EMU8086.

**Technologies Used:**
Assembly Language · EMU8086 · 8086 Microprocessor Architecture

**Features:**
- Main menu navigation
- Bus schedule display
- Bus selection and reservation
- Invalid-selection handling
- Fare calculation, with or without student discount
- Final bill display
- Program exit

**Program Flow:**
The program is structured around a set of labels that drive its core logic:
- **START** — entry point and main menu
- **SHOW** — displays the bus schedule
- **RESERVE** — handles bus selection and reservation
- **CALCULATE** — processes fare calculation
- **BILL** — displays the total and checks discount eligibility
- **DIS_30** — applies the 30% student discount
- **NO_DIS** — displays the total with no discount
- **EXIT** — ends the program
- Additional labels manage invalid selections and cases with no active reservation.
